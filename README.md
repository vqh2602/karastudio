# KaraStudio

KaraStudio is an independent Flutter desktop editor for karaoke subtitle projects. It uses its own JSON-based `.karastudio` format and FFmpeg for real media inspection and waveform extraction.

## Current implementation

- Desktop editor shell for macOS and Windows with resizable/collapsible panels, dark/light themes, keyboard shortcuts, and transport controls.
- New, open, atomic save, save-as, recent-project tracking, autosave recovery snapshots, project validation, and a 100-step command history foundation.
- Audio import through FFprobe, playback through `media_kit`, seeking, playback speed, and cached multi-resolution waveform peaks generated by streaming FFmpeg output.
- Integer microsecond timestamps throughout the project model.

Lyrics editing/timing, karaoke rendering, styling, effects, and export are intentionally developed as subsequent vertical slices on top of this foundation.

## Development

Requirements: Flutter 3.41 or newer and FFmpeg/FFprobe on `PATH`. On macOS, KaraStudio also checks Homebrew's `/opt/homebrew/bin` and `/usr/local/bin` locations.

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d macos
```

Build with `flutter build macos` on macOS or `flutter build windows` on Windows.
